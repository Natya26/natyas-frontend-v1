# Indhriya

Welcome to the **Indhriya** ! This is a React-based application developed with TypeScript, designed to provide a seamless experience for streaming web series, and other video content. The platform offers features like user authentication, content browsing, search functionality, and more.

## Table of Contents

- [Features](#features)

- [Usage](#usage)

## Features

- **User Authentication**: Secure login and registration system.
- **Content Browsing**: Browse and filter content by genre, popularity, and more.
- **Search Functionality**: Search for series, and other video content.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **User Profiles**: Manage watchlists and viewing history.
- **Video Playback**: Stream video content with custom player controls.
- **Admin Panel**: Manage content, users, and platform settings (for admins).

## Installation

### Prerequisites

- **Node.js** 
- **npm**  or **yarn**

### Setup

1. **Clone the repository**:

   ```bash
   git clone https://github.com/indhriya/indhriya-frontend-service
   cd indhriya-frontend-service
   ```

2. **Install dependencies**:

   Using npm:

   ```bash
   npm install
   ```

   Or using yarn:

   ```bash
   yarn install
   ```


3. **Run the application**:

   Using npm:

   ```bash
   npm start
   ```

   Or using yarn:

   ```bash
   yarn start
   ```

   The application will be accessible at `http://localhost:3032`.

## Usage

- **Browse Content**: Navigate through different categories and genres.
- **Search**: Use the search bar to find specific content.
- **Watch**: Click on a title to view details and start streaming.
- **Profile Management**: Access your profile to manage your data and subscription.
